# Machine Learning Classification Evaluator

**Author:** Chandan Srinivas Siddey  
**Registration Number:** 2025NS04126  

## Project Overview
This project evaluates multiple machine learning classification models (Logistic Regression, Decision Tree, KNN, Naive Bayes, Support Vector Machine) on the Breast Cancer diagnostic dataset. The application allows users to upload test data, apply pre-fitted standard scaling, and dynamically generate evaluation metrics (Accuracy, AUC, Precision, Recall, F1, MCC) alongside a confusion matrix.
